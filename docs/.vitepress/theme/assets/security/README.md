# Security integration logos

- `cloudflare.svg`: the monochrome Cloudflare wordmark used by the Vite+ site (`docs/.vitepress/theme/assets/platforms/cloudflare.svg` in the Vite+ repository).
- `google.svg`: [Iconify Logos — Google](https://api.iconify.design/logos/google.svg).
- `github.svg`: [Iconify Logos — GitHub](https://api.iconify.design/logos/github.svg).
- `openid.svg`: [Simple Icons — OpenID](https://api.iconify.design/simple-icons/openid.svg), paired with the OIDC label.

The homepage displays these assets in monochrome to match the Vite+ logo strip.
