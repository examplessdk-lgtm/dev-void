# Former implementation tracker

The original phase-by-phase launch checklist is retired. It tracked an earlier
hosted product, mixed shipped features with proposals, and is not a roadmap or
an installation checklist for a self-hosted platform. Its history remains in Git.

Use these maintained documents instead:

- [Self-host a Void platform](../../docs/guide/self-hosted-platform.md) for the supported core and installation requirements.
- [Platform Administration](../../docs/guide/platform-administration.md) for day-to-day operations.
